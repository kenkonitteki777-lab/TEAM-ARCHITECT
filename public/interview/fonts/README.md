# Interview fonts

Japanese: IBM Plex Sans JP Regular / Medium / SemiBold, retrieved from the official Google Fonts repository on 2026-10-07. Source: https://github.com/google/fonts/tree/main/ofl/ibmplexsansjp

The Japanese fonts are subsetted to the application text, Latin, kana and full-width punctuation for fast loading. The modified font family is renamed to **Interview Sans JP** in accordance with the reserved name in the included SIL Open Font License. Characters outside the subset use the platform font. Original copyright notices are retained.

Latin: unmodified Manrope variable font, converted to WOFF2. Source: https://github.com/google/fonts/tree/main/ofl/manrope

Both licenses are included alongside the fonts. No external font request is needed.
