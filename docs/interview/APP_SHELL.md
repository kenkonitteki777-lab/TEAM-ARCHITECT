# 面接アプリ：3画面と再開（2026-10-18 JST）

対象：`public/interview/`。同居するTEAM ARCHITECT本体は変更しない。
公開版指定：`/interview/?v=20261018-shell1`。

## 完了した変更

- 下部ナビを「練習・過去問・設定」の3画面へ整理。
- ヘッダーと各ダイアログの「最初に戻る」は練習トップに戻る。登録済み質問・回答・履歴は消さない。
- 練習中の「1問目へ」は現在の出題範囲・面接官の先頭へ移動する。
- トップの再開カードに前回の質問・面接官・モード・範囲を表示。「変更する」で設定、開始で練習へ。
- 過去問の取り込み・追加・日付検索・編集を過去問画面へ集約。未保存のフォームを離れる際は破棄確認。取消なら入力を保持。
- 設定画面に1回の出題数（1/3/5/10）、部長・社長の回答時間、文字サイズ、音声、バックアップ、履歴を集約。
- 実戦練習の計測は設定・過去問・練習設定を表示中は一時停止する。
- 再読み込み後はトップから質問単位で再開。発話途中の時間や音声を自動再生しない。AIへの自動送信はしない。

## 保存互換性

既存の質問・回答・履歴・音声・下書きのキーと形式は維持。新規キー：
`team_architect_app_preferences_v1`、`team_architect_session_v1`、`team_architect_backup_exported_at`。
最後のキーはダウンロード操作を実行した時刻。ファイルの保管完了の保証ではないため「最終書き出し」と表示。
古い位置保存も引き続き読み取る。失われた選択範囲や空になった苦手範囲は全問へ戻し、有効な面接官と質問を選ぶ。
設定保存に失敗した場合は前の設定を維持する。
既存JSONバックアップは引き続き質問・回答・履歴を移行する。今回のアプリ表示設定・再開情報は端末ごとの設定で、バックアップには含まない。
