# 過去問取り込み・練習モードの整理 — 2026-10-16

## 操作の変更

トップに「まとめて取り込む」「＋1問追加」「過去問を探す」を配置。質問一覧を経由する必要をなくした。

面接官（部長／社長）と練習方法（確認・編集／実戦練習／AI面接）を別々に選ぶ。実戦・AIは選ぶと開始し、確認・編集へ戻ると口頭練習を終了する。出題範囲は全問、登録した過去問、自分で追加した質問、苦手な質問、今回取り込んだ質問。

1問追加は質問・回答を先に入力する。日付・面接官・出典は折りたたんだ設定に移動。面接官はトップの選択を初期値にする。

## まとめて取り込む

- 文章貼り付け：Q／A形式、番号付き質問、1行1問、日付・面接官・出典の見出し。
- Excelのセルをコピーしたタブ区切りの表。質問・回答の2列だけでも可。
- TXT・CSV・TSVファイル。UTF-8・BOM・Shift-JISの読み込みに対応。
- CSVの列見出し：質問、回答、出題日、面接官、テーマ、出典、区分。英語の基本見出しも可。ファイルの見出しなしはこの列順。
- PDF・Wordは文章をコピーして貼り付ける。PDFや画像の直接解析・OCR、Excelファイルそのものの読み込みは未対応。画面に対象形式を表示。

入力 → 内容確認 → 保存。確認画面で質問・回答・日付・面接官などを修正できる。まだ保存していない時点では質問データを変更しない。一度に300問、ファイル2MB、文章100万文字、質問2000文字、回答12000文字まで。

同じ質問文（空白・全半角を正規化）＋面接官＋出題日の組み合わせは既存と一致として、初期状態で未選択にする。更新する行を本人が選んだ場合のみ、元のIDを維持して更新する。同じ本文で別の出題日は別の過去問として保持。取り込み内の重複も未選択。確認中に質問・日付を変えて既存と衝突した場合は、選択を外して明示的な選び直しを求める。別タブで新たに同じ質問が登録された場合も、確認し直すまで上書きしない。

全選択分の検証が通ってから1回のlocalStorage書き込みで保存。容量エラーや入力エラーで途中の行だけを登録しない。入力・確認内容は画面を閉じてもメモリーに保持するが、ページ再読み込みを越える下書き保存ではない。

保存後に「取り込んだ質問を確認」「この過去問で実戦練習」を選べる。後者は今回のIDだけを出題範囲にする。範囲の選択はそのページ内で有効。追加した質問本体・日付・回答は従来の端末保存とバックアップに含まれる。

## 空の範囲・AIとの関係

空の範囲は選択を確定せず、理由を案内。対象のない面接官へ切り替えて空画面にしない。苦手な質問をすべて克服した後の終了時は全問へ戻す。

取り込んだ質問・本文変更分のAI評価は引き続き未対応。口頭の実戦練習と通常の確認・編集には対応。既存のAI認証・同意・固定質問の範囲は維持する。
