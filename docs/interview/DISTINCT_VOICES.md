## 生成・配信

`scripts/export-interview-audio.mjs`が公開質問だけをカタログ化する。本人入力・回答・登録事実は書き出さない。

GitHub Pagesの既存ビルドで公式VOICEVOXエンジン0.25.2の固定ダイジェストのCPUイメージを使い、異なるspeaker_idで音声生成。声の名前とスタイルをエンジンから照合し、同一speaker_idなら失敗させる。

音声は24kHzモノラル、64kbps MP3。生成WAVの時間とRMSを検査し、空音声を拒否する。生成済みMP3をキャッシュするため、同じ質問と設定なら再合成しない。スマホでは音声モデルをダウンロードせず、聞くクリップだけ取得する。

`audio/manifest.json`にエンジン、声名、speaker_id、各クリップの時間・サイズを記録。個人のメール・認証情報は含めない。

現行カタログは重複を除いた128クリップ。本物の生成・公開はビルドと公開manifestで確認する。ローカルの合成API代替テストを実VOICEVOX音声の検証と混同しない。

## 自然な話し方の調整 — natural2

声の種類は維持し、生成時の話し方を変更。社長の速度1.08を1.0へ戻し、部長も1.0。抑揚は部長1.12・社長1.08。読点の間は部長0.18秒・社長0.22秒、文間は0.36秒・0.42秒。エンジンのアクセント位置・音高を維持する。句読点とエンジンの間の数が一致しない場合は元の間を保持する。架空の息音や無作為な揺らぎは追加しない。

音声パスに改訂識別子を含め、古いMP3のブラウザーキャッシュを回避。生成スクリプト依存ファイルもCIキャッシュキーに含める。無料エンジンによる合成であり、人間の録音と同じ自然さは保証しない。自由なAI追撃・編集解答は端末音声のまま。
