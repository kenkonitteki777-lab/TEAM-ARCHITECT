# 面接UI：直接切り替えへ修正（2026-10-18 JST）

`APP_SHELL.md` の練習トップ＋設定ダイアログ方式は、操作が増えて使いづらいという本人の指摘により廃止。現在の正本はこの文書。

## 操作

- ページを開くと、前回の質問・面接官・出題範囲をすぐ表示する。初期モードは「質問・回答」。自動で計測・AI接続・送信を始めない。
- 「質問・回答／声で練習／AI面接」の3ボタンを質問の上に常設。1タップで切り替え、設定を開く・適用する・再度開始する操作をなくした。
- AI画面内にも同じ切り替えを用意。AIから質問確認・声で練習へ1タップで戻れる。
- 「部長／社長」と出題範囲も常設。声で練習中に変更した場合は、選んだ質問で同じ声の練習モードを開始する。現在の未完了計測は新しく開始するが、保存済みの履歴は維持。
- 「最初に戻る」はダイアログを閉じ、現在の質問の確認画面へ戻す。「1問目へ戻る」は現在の範囲と面接官の先頭へ戻す。
- 下部は練習／過去問・回答／設定。過去問では追加と取り込みを1か所ずつ設置。検索と日付を表示し、年・月・区分・面接官は詳細絞り込みにまとめた。
- 未保存の質問を編集しているときに別画面・取り込みへ移動すると破棄確認。取消時は内容を保持。
- 質問を主役にした簡潔な配色と文字へ調整。スマホでも部長・社長のキャラクターを質問の横に表示する。画面幅に合わせてサイズを調整し、直接切り替えと両立する。PCのキャラクター表示も維持する。

## 保存と互換性

質問・回答・履歴・音声・バックアップの保存キーと形式を維持。以前のセッション設定も読み込み、質問・面接官・範囲を復元する。新しい課金API・認証・データベースの変更はない。
設定・過去問へ移動中の声の練習タイマー停止も維持。
