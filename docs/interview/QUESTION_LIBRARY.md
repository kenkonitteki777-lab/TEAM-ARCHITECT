# 本人用の過去問・質問管理 — 2026-10-16

## 操作

質問一覧 → 過去問の追加・年月日で見る → 質問と回答を追加。

質問、回答（空欄も可）、出題日（任意）、面接官、過去問／想定質問／出題状況未確認、テーマ、出典を登録する。一覧から既存・追加質問の両方を編集できる。練習画面の「質問・出題日を編集」からも開く。

年月日・面接官・区分・キーワードで検索。出題日の新しい順に日付別表示し、日付不明は別グループにする。既存質問の資料名から年月日や実出題を推測しない。既存74問は初期状態で日付不明・出題状況未確認。

## 保存・互換性

- `team_architect_question_library_v1` に本人編集分だけを保存。公開質問ファイルは書き換えない。本人入力をGitHubや音声生成CIに送らない。
- 追加IDは `u-UUID`。元の質問はIDを維持し、練習履歴・回答編集との対応を維持する。
- 既存の回答編集と質問管理の回答は更新日時を比較し、新しい回答を表示する。
- IndexedDBにも追加質問のコピーを保存。保存容量エラー時は成功扱いせず、フォームの入力を保持。編集中の閉じる・一覧に戻るには破棄確認。
- バックアップに `questionLibrary` を追加。読み込みは先に質問カタログを検証・統合してから、追加IDの回答・履歴を検証する。旧バックアップも読み込み可。既存データは日時比較で統合する。
- ログインによる自動同期は実装していない。この端末への保存であり、移行にはバックアップを使用する。

## 練習と制約

追加質問は通常表示・回答編集・読み上げ・実戦練習・復習・履歴に対応。想定追撃0件でも練習できるようステップ数を可変にした。追加質問や本文を変えた質問は端末音声になる。

AIサーバーは公開済み固定カタログだけを扱う。追加質問・本文または面接官を変えた質問はAI面接に送らず、実戦練習を案内する。「次の質問」でも対象外の質問を飛ばす。日付や回答だけを編集した既存質問のAI面接は維持。
