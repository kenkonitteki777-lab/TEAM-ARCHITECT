# 面接アプリ：操作性と学習品質の改善（2026-10-25 JST）

対象は `public/interview/` の面接アプリ。同居するTEAM ARCHITECT本体は変更しない。部長・社長のキャラクターと面接官別の専用音声を維持。

## 完了

- モード選択を画面上部に追従。回答の下へスクロールした後も、質問確認・声の練習・AI面接を直接切り替えられる。
- 縦持ちは面接官と出題範囲を同じ行にまとめ、質問の表示位置を上げた。下部の操作欄をコンパクト化。横持ちは操作設定と質問・キャラを左右へ配置し、画面ナビを右端へ移動する。
- 「今回○問」は対象範囲と設定から実際の出題数を計算。練習中の出題数と目安時間は開始時点の値を維持し、設定変更は次の練習へ反映。
- 声の練習は「答えられた／要復習／未評価で残す」の明示選択後に保存。未選択で自動的に成功扱いにしない。未評価で保存しても過去の要復習や本人の回答を消さない。
- 自己評価・AI評価の違いを表示。追加・本文変更した質問はAIボタンを無効化し、理由と対応質問への移動を先に案内。AIバックエンドの対象拡張は行っていない。
- 「今日○問練習」「要復習○問」を表示し、要復習範囲へ直接移動。日付判定は日本時間、回数は本質問の質問ID単位で集計。追撃を別の質問数として加算しない。
- 専用音声と端末音声の設定を分離。固定質問の試聴は従来の専用MP3、端末の声・高さの試聴は実際に端末TTSを使う。端末設定を変えて固定MP3の声も変わるように見える問題を解消。
- 過去問一覧に回答プレビューと「追加した質問／回答の要確認」の絞り込みを追加。本人の実績・数字を補う質問を探して、その場で編集できる。
- 画面を移動した際に、前の画面の通知を残さない。未保存フォームの破棄確認、追加・一括取り込み・バックアップ復元を維持。
- 新しいUI文言も欠けずに表示できる日本語フォントのサブセットを追加。元のIBM SIL OFLを維持し、フォント名はInterview UIに変更。不要になった見出しフォントの先読みを新UIフォントへ置換。

## 保存互換性

既存の質問・回答・履歴・音声・出題設定の保存キーを維持。履歴は既存のv3形式で、未評価は従来から許容される `grade:null`。以前の記録を再採点・削除しない。
データは引き続き端末保存。クラウド同期や新しい課金APIは追加していない。
日付や本人の実績は推測で補完しない。初期74問の不明な出題日や回答の要確認部分は、本人の資料をもとに今後整備する。
